# اعتذار إلى تهجد ❤️

الموقع صفحة ثابتة بالكامل باستخدام `index.html` و`style.css` و`script.js` فقط. لا يحتاج إلى خادم أو قاعدة بيانات أو مكتبات خارجية.

## إضافة الأغنية

لم يُرفق ملف الأغنية مع الطلب. ضعي النسخة التي تملكينها في المجلد نفسه مع الملفات الثلاثة، وسمّيها بالضبط:

```text
song.mp3
```

سيبدأ تشغيلها عند الضغط على **Yes ❤️**. إذا لم يكن الملف موجودًا، ستظهر رسالة الاعتذار بشكل طبيعي وسيظل بإمكانك قراءة الصفحة.

## رفع الموقع إلى GitHub Pages

1. أنشئي مستودع GitHub جديدًا.
2. ارفعي إلى جذر المستودع الملفات `index.html` و`style.css` و`script.js` و`song.mp3`.
3. افتحي **Settings → Pages**.
4. اختاري **Deploy from a branch**، ثم فرع `main` ومجلد `/(root)`، واضغطي **Save**.
5. بعد اكتمال النشر، افتحي الرابط الذي يعرضه GitHub Pages.

استخدمي ملفات الموقع الثلاثة من هذا المجلد؛ لا حاجة لرفع ملفات المشروع الأخرى أو تشغيل عملية بناء.
